VOLLEYDATA v0.1 - BASE PROJECT

FIRST TIME:
1. Install Node.js (LTS) on this computer.
2. Open this VOLLEYDATA_v0.1 folder.
3. Double-click start.bat.
4. Wait until CMD displays a Local address, usually http://localhost:5173/
5. Open that Local address in your browser.
6. Keep the CMD window open while using the website.

FUTURE VERSION UPDATE:
Each update ZIP will contain only:
src/
  main.tsx

Extract the update ZIP, copy the new main.tsx, and paste it into:
VOLLEYDATA_v0.1/src/
Choose Replace the file in the destination.
Then refresh the browser. If needed, stop and restart start.bat.

IMPORTANT:
The active application is the one main.tsx file inside VOLLEYDATA_v0.1/src.
Do not keep multiple files named main.tsx in the same src folder.
Keep old update ZIP files separately as version backups.
